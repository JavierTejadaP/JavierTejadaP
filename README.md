### 🚀 Featured project

**[GrabadoraClases](https://github.com/JavierTejadaP/GrabadoraClases)** — an Android app that records
university classes following your timetable.

- Knows which class is on and reminds you to record it
- Keeps recording with the screen off; bookmarks for the important moments
- Search past classes by topic, export a whole course as a ZIP
- Kotlin · SQLite · Coroutines/StateFlow · unit tests · GitHub Actions CI
